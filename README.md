# Amazon Sales Data Analysis

**An End-to-End Data Analytics Project | Excel • Python • SQL • Power BI**

---

## 📌 Project Overview

This project focuses on analyzing Amazon Sales Report data to understand sales performance, product trends, category contribution, order status, and fulfilment patterns.

The objective is to transform raw sales data into meaningful business insights using data inspection, cleaning, analysis, and interactive visualization.

## 🎯 Project Objectives

- Understand overall sales performance.
- Analyze revenue and order trends.
- Identify top-performing products and categories.
- Examine product size and quantity patterns.
- Analyze order and courier status.
- Build interactive dashboards to support data-driven decisions.

## 🛠️ Tools & Technologies

| Tool                   | Purpose                                  |
| ---------------------- | ---------------------------------------- |
| Microsoft Excel        | Data inspection and initial analysis     |
| Python (Pandas, NumPy) | Data cleaning and preparation            |
| SQL                    | Data querying and analysis               |
| Power BI               | Interactive dashboards and visualization |

## 📂 Project Workflow

### 1. Data Inspection – Excel

- Initial dataset exploration.
- Identification of missing values.
- Duplicate record inspection.
- Understanding column structure and data quality.

### 2. Data Cleaning – Python

- Data loading and exploration using Pandas.
- Missing-value analysis.
- Data type and column inspection.
- Data preparation for further analysis.

### 3. Data Analysis – SQL

- SQL-based data exploration and analysis.
- Business-focused queries.
- Analysis of sales and product performance.

### 4. Dashboard Development – Power BI

- Interactive dashboard development.
- KPI visualization.
- Product and category performance analysis.
- Order and fulfilment trend analysis.

## 📊 Power BI Dashboard

The dashboard is organized into three analytical pages:

**Page 1 – Executive Sales Dashboard**

- Overall sales performance.
- Revenue trends.
- Category and fulfilment analysis.
- Order status breakdown.

**Page 2 – Product & Category Analysis**

- Top 10 Products by Revenue.
- Top 10 Products by Quantity Sold.
- Sales by Size.
- Average Selling Price by SKU.
- Quantity Sold by Category.

**Page 3 – Order & Courier Analysis**

- Courier status analysis.
- Monthly order trends by courier status.
- Additional order-related visualizations.

## 💡 Key Learning Outcomes

- Practical experience with a real-world sales dataset.
- Understanding of data quality and cleaning.
- Combining multiple data analytics tools.
- Building interactive business dashboards.
- Translating data into meaningful visual insights.
